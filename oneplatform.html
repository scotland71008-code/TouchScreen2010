Documentation & User Guide

Getting Started

Signing In

Navigate to OnePlatform and enter your credentials. The following accounts are available for this demo:

  • Sherin / Octave123 — Project Engineer (full access)
  • Harish / Octave123 — Design Engineer (Features section hidden)
  • Sridhar / Octave123 — Construction Lead (Create & Features sections hidden)
  • Admin / Octave123 — System Administrator (full access + Administration panel)

Switching Projects

Click the project name button in the top header bar to switch between the three demo scenarios: TestDownstream (onshore refinery, mid-EPC), TestOffshore (FPSO topsides, early engineering), and TestMaintainPotential (brownfield maintenance, UAE). All dashboards, charts and task tables update instantly.

Main Dashboard

Lifecycle Phase Tabs

The top tabs filter all content by engineering phase: Detailed Engineering, Construction Execution, and Commissioning & Handover. Selecting a phase filters the task table below to show only relevant items.

KPI Summary Cards

The four cards at the top show at-a-glance counts for documents in review, change requests, submittals and QA items. Click any card to filter the task table to that category.

Data Sync Bar

Pull live data from each Hexagon system individually using the seven pull buttons (Smart 3D, Smart P&ID, Smart Instrumentation, Smart Electrical, Smart Construction, Smart Materials, Smart Completion). Once all systems are pulled, click Push to OnePlatform to consolidate the data and refresh all dashboards.

Chart Drill-Down

Click any segment of the discipline or document-type charts to filter the task table to that discipline or type. A blue banner confirms the active filter. Click the banner's × to clear it.

Reports & Dashboards

Opening the Hub

Click the Reports icon (chart icon) in the left sidebar to open the full Reports & Dashboards hub. It slides in over the main content without losing your dashboard state.

Tabs Overview

  • Engineering — IFD/IFC/As-Built milestones, discipline document status, open change requests
  • Information Management — Document register, type distribution, approval workflow, Hexagon system sync status
  • Procurement — PO line items, material by status, site inventory
  • Construction — Work package register, progress by trade, priority distribution
  • Completions — Subsystem completion status, punch list Cat A/B, SAP AIN handover

Drill-Down & Cross-Navigation

Click any underlined ID in any table (doc number, PO number, WP ID, punch item) to open a cross-reference panel. This shows full item metadata, any related tasks, and Navigate To buttons that jump directly to the relevant tab.

Click any chart segment or bar to open a filtered detail table in the drawer at the bottom. Toggle between donut and bar views using the icons in each card's header.

Exporting to Excel

Click the green Export Excel button in the Reports hub header to download the current tab's data as a multi-sheet .xlsx file. Each sheet corresponds to a data table in that tab (e.g., Completions exports subsystems + punch list as separate sheets).

Administration (Admin only)

The Administration panel is only visible after signing in as Admin. It appears as a shield icon at the bottom of the left sidebar.

User Management tab

Displays a card for every registered user showing their avatar, display name, username, and current role. For non-admin users the role title is editable — type a new title in the field and click Save. The change takes effect immediately and updates the avatar menu if the user is currently signed in.

Access Control tab

Shows a permission matrix: rows are application sections (Dashboard, Search / Browse, Create, Reports, Activity, Todo List, Features, Documentation) and columns are users. Each cell contains a toggle switch. Turning a toggle off removes that user's access to the section; turning it on restores it. Changes apply instantly — if the affected user is currently viewing a restricted section they will see an "Access restricted" toast on their next navigation attempt. Admin's column is locked and always shows full access.

Global Search

Press Ctrl+K (or Cmd+K on Mac) anywhere to open the global search. Use the type selector to filter by Tags, Documents, Transmittals, Change Requests, or search All. Recent and saved searches appear in the dropdown. Results are scoped to the active project.

Hexagon Systems — OnePlatform Integration

OnePlatform aggregates data from seven Hexagon engineering applications into a single unified view. Each system can be pulled individually and consolidated via the Push to OnePlatform workflow.

Smart 3D

3D plant design and model authoring. OnePlatform surfaces clash detection results (hard and soft clashes), model discipline coverage, and resolution status. Click the Smart 3D pull button to sync the latest clash report.

Smart P&ID

Intelligent P&ID authoring and management. OnePlatform tracks total P&ID count, approval status (Approved / In Review / Draft), and revision history. Drives the Engineering tab's IFD/IFC milestone tracking.

Smart Instrumentation

Instrument loop design and datasheet management. OnePlatform shows loop completion status (complete, in-progress, pending) and surfaces related instrument datasheets in the document register.

Smart Electrical

Cable routing, termination and electrical schedule management. OnePlatform tracks cables routed vs terminated, schedule count, and links electrical documents to area-based status views.

Smart Construction

Advanced Work Packaging (AWP) and construction execution management. OnePlatform exposes Construction Work Packages (CWPs) with status, trade, area, priority and progress percentage in the Construction tab.

Smart Materials

Material procurement tracking from PO creation to site delivery. OnePlatform shows PO line items, fulfilment percentages, site inventory (On Site / In Transit / Ordered / Backlog), and links materials to construction work packages.

Smart Completion

Commissioning and handover management. OnePlatform tracks subsystem completion status, punch list items (Cat A safety-critical / Cat B non-safety), ITR progress, and SAP AIN asset synchronisation readiness for handover.

OnePlatform

The aggregation layer. Consolidates outputs from all seven systems into unified dashboards, cross-discipline reports, and a single task inbox. Pull individual systems then Push to OnePlatform to refresh the consolidated view.

Data Flow

  1. Each Hexagon system maintains its own live dataset (3D model, P&IDs, instrument loops, cables, work packages, materials, completion records).
  2. The Pull buttons in the sync bar fetch the latest snapshot from each system into OnePlatform's staging area.
  3. Push to OnePlatform merges all pulled snapshots, recalculates KPIs, updates milestone progress, and refreshes all dashboard charts.
  4. The consolidated data is then available across the Reports hub, task inbox, and drill-down panels.

About OnePlatform

OnePlatform is an engineering and construction information management hub built on the Hexagon Systems Suite. It integrates Smart 3D, Smart P&ID, Smart Instrumentation, Smart Electrical, Smart Construction, Smart Materials and Smart Completion into a unified project lifecycle view — from Detailed Engineering through Construction Execution to Commissioning & Handover.
